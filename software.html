Software

Scientific computing tools developed alongside my research.

01

CompOSE → SRO EOS Converter

A Python tool for converting equation-of-state tables from the CompOSE database into a format compatible with the Schneider-Roberts-Ott (SRO) representation used by GR1D workflows.

The converter handles the required table structure, physical definitions, units, derivatives, and low-temperature / low-density extrapolation needed for use with the GR1D interpolation scheme.

02

GR1D Visualization & Analysis

Tools for processing and visualizing output from GR1D simulations, supporting analysis of shock evolution, thermodynamic quantities, oscillations, and other simulation diagnostics.

This project is intended to make repeated analysis of large sets of simulations more reproducible and efficient.

View on GitHub
03

Model-Agnostic GRB MCMC Pipeline

A Python-based Monte Carlo Markov Chain framework developed during my University of Utah REU to automate sampling across gamma-ray burst afterglow modeling codes.

The pipeline was designed to be model-agnostic and was used to benchmark parameter recovery across GAMMA, PyFRS, and VegasAfterglow and investigate degeneracies in fitted parameters.
